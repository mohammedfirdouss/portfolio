# InfraAlert

InfraAlert is an **AI-powered multi-agent system** for reporting infrastructure problems and coordinating the response. It is built on Google Cloud Platform with the Agent Development Kit (ADK). It takes reports from citizens, analyzes them with AI, and turns them into coordinated responses.

## Core Architecture

The system uses a microservice design: each agent is its own Cloud Run service, and a central Orchestrator coordinates them.

1.  **Orchestrator Agent**: The central workflow coordinator.
2.  **Issue Detection Agent**: Reads and classifies issues using Vision API, NLP, Speech-to-Text, and Gemini AI.
3.  **Priority Analysis Agent**: Scores each issue's priority based on how severe and urgent it is, and on past patterns.
4.  **Resource Coordination Agent**: Matches issues to nearby teams and assigns resources.
5.  **Platform Integration Agent**: Sends notifications to outside services, including low-cost SMS via Africa's Talking.
6.  **Policy Agent (RAG)**: Answers questions from infrastructure policy documents using RAG (retrieval-augmented generation).

## Key Features

- **Multi-Channel Intake**: Takes web, mobile, and voice reports in English, Yoruba, Hausa, and Igbo.
- **AI-Driven Analysis**: Processes text, photos, and audio in real time to detect and sort infrastructure failures.
- **Intelligent Prioritization**: Rates how serious each issue is automatically, so critical issues are handled first.
- **Real-Time Tracking**: A web application for citizens, built with React and Vite, to report issues and follow their status.
- **Serverless & Scalable**: A fully serverless stack using Cloud Run, Firestore, and BigQuery, which scales to zero when idle.

## Tech Stack

- **AI/ML**: Gemini 1.5 Pro, Google Vision API, Speech-to-Text, Natural Language API.
- **Backend**: Python 3.12, FastAPI, Flask, Google ADK.
- **Frontend**: React, Vite, TypeScript.
- **Cloud**: Google Cloud Platform (Cloud Run, Pub/Sub, Firestore, BigQuery, Cloud Build).
- **Integrations**: Africa's Talking (SMS), Google Maps (Geocoding), Model Context Protocol (MCP).
