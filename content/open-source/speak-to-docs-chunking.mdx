Speak to Docs lets users upload documents and ask questions about them with retrieval-augmented generation (RAG).

I added a `chunk_document` function that splits uploaded documents with LangChain's `RecursiveCharacterTextSplitter`, and called it from `extract_contents_from_doc`. Smaller chunks mean retrieval can return the sections that actually answer the question.
