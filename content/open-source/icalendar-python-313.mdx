I worked on Python 3.13 support for icalendar. My PR added 3.13 to the test matrix, tox config, classifiers and README, but a parallel change landed the test setup on `main` while it was in review. After merging `main`, my final contribution was:

- documenting how to add a new Python version in `docs/maintenance.rst`, so the next upgrade is easier,
- the changelog entry for 3.13 support.
