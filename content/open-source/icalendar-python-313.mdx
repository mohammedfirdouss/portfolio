I added Python 3.13 to icalendar's supported versions:

- added 3.13 to the GitHub Actions test matrix and the tox config,
- updated the classifiers in `pyproject.toml` and the README,
- documented how to add a new Python version in `docs/maintenance.rst`, so the next upgrade is easier.
