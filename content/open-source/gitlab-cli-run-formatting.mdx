I updated the help examples for GitLab CLI release commands to match the project’s doc style (`$` for commands, `>` for output, `#` for comments).

This was a small docs cleanup, but it makes the help text easier to scan and keeps it consistent across the CLI.

I updated the `create`, `delete`, `download`, `upload` and `view` commands under `commands/release/`, and regenerated their pages in `docs/source/release/`.

Merged quickly after maintainer review.
