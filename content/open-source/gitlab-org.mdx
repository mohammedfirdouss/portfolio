I fixed a broken step in GitLab’s developer tutorials. The tutorials asked readers to search for text that no longer existed in the codebase.

Both the GDK and Gitpod setup docs told contributors to look for old text (`Customize the color of GitLab`), so the exercise failed for new contributors.

I updated the tutorials to use text that still exists (`Syntax highlighting theme`), so new contributors can finish the setup steps without hitting a dead end.

It was a small fix, but it removed a real pain point for new contributors. It was merged after docs review.
