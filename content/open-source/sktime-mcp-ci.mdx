`sktime-mcp` exposes the sktime time-series library through the Model Context Protocol. It had no CI, so I added a GitHub Actions workflow that runs on every push and PR:

- a **lint** job running `ruff` and `black --check` with the project's existing config,
- a **test** job running `pytest` on Python 3.9, 3.10, 3.11 and 3.12, with `fail-fast` off so every version reports.

It added no new dependencies, since the tools were already in the project's dev extras.
