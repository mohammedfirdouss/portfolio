PipeCD was moving its built-in stages into plugins for its new `pipedv1` architecture. I wrote the first PR for the Analysis stage plugin, which watches metrics during a deployment.

What shipped in [#6097](https://github.com/pipe-cd/pipecd/pull/6097):

- a new stage plugin under `pkg/app/pipedv1/plugin/analysis/`, following the same pattern as the existing `scriptrun` plugin,
- stage definitions and pipeline sync stage building,
- config decoding, with tests for empty and invalid configs.

It was planned as the first of several PRs, keeping the analysis logic itself for later work so the structure could be reviewed on its own.
