ADK Investment Research Agent is a multi-agent pipeline. You give it a company name or stock ticker, and it returns a structured investment report. It uses Google's Agent Development Kit (ADK) to run a team of agents: a researcher, an analyst, a critic, and two parallel case writers. It runs on Google Kubernetes Engine Autopilot.

## What it is

A production-ready multi-agent research system with:

- **Orchestration:** A sequential root agent runs a research team in a loop (up to 3 rounds), then hands the result to the report writers.
- **Analyst-Critic Loop:** The analyst proposes an investment thesis. The critic challenges it. The loop repeats until the thesis passes or the round limit is reached.
- **Parallel Case Writing:** The bull and bear cases are written at the same time by two separate agent branches.
- **GKE Autopilot Deployment:** The full pipeline runs as a containerised FastAPI service with Cloud Logging.

## How It's Built

- **Agent Framework:** Google Agent Development Kit (ADK) 1.27.5 with a `SequentialAgent` root and a `LoopAgent` research team.
- **LLM Backend:** Gemini 2.5 Flash for all reasoning steps.
- **Research Tool:** Wikipedia API via LangChain Community integration.
- **Serving Layer:** FastAPI + Uvicorn, containerised for Kubernetes.
- **Infrastructure:** GKE Autopilot with Cloud Logging for structured log output.
- **State Flow:** `PROMPT` → `research` → `INVESTMENT_THESIS` passed through shared agent state.

## What I Learned

- **Multi-Agent Design:** How to combine sequential, looping, and parallel agent patterns in one ADK pipeline.
- **Feedback Loops in AI Systems:** How to design critic agents that improve results step by step without looping forever.
- **Cloud-Native AI Deployment:** How to package an agent workload for GKE Autopilot and set up structured logging.
- **State Management:** How to pass structured state between agents cleanly in a stateful pipeline.
