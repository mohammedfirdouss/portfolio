TerraTowns takes after the self-hosted spirit of Geocities. It started as a hands-on Terraform bootcamp: each "Terraformer" writes Terraform code that sets up and deploys a simple CMS, their "Terra House".

Behind it are a custom Go provider, AWS (S3, CloudFront and Lambda), and a Ruby mock server for local development.
