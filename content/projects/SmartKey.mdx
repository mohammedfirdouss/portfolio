Staff request a key, collect it at the security desk with a one-time code, and return it the same way. Every step is logged and timestamped, and the AI features flag what a paper logbook never could, such as a signature that doesn't match.

Built with Next.js, TypeScript, and Supabase (Postgres with Row-Level Security), with the Google Gemini API for AI features.
