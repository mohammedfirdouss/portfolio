*   Built the full `kubernetes_multicluster` plugin for PipeCD with six pipeline stages: canary rollout, baseline rollout, primary rollout, traffic routing, canary clean, and baseline clean. This lets PipeCD roll out changes step by step across multiple Kubernetes clusters.
*   Made deployments safer by using `pipecd.dev/variant` labels to keep resources separate, so canary and baseline workloads can be cleaned up on their own without touching production resources.
*   Made multi-cluster operations more reliable by running cluster operations in parallel with Go's `errgroup` pattern, and by adding per-route logging so traffic routing is fully visible.
