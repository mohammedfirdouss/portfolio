## Architectural Overview

The Terra Towns architecture is built to be simple and scalable. It uses AWS services plus Terraform to manage the infrastructure.

-   **Content Delivery:** Amazon CloudFront works as the content delivery network (CDN). It caches the website content at locations around the world, so users get fast access wherever they are.
-   **Website Hosting:** The website is a static site stored in an Amazon S3 bucket. This is a reliable, low-cost way to host a website that does not need a traditional server.
-   **Infrastructure as Code:** All the cloud infrastructure is defined and managed with Terraform. Deployments are automated, repeatable, and version-controlled.

## Why This Architecture?

This design was chosen because it is efficient and reliable:

-   **High Availability:** S3 and CloudFront are both highly available services, so the website stays reachable.
-   **Global Scale:** CloudFront runs a global network, so the platform can serve users worldwide with low latency.
-   **Automated Management:** With Terraform as infrastructure as code, the whole environment can be created, updated, or copied automatically. This cuts manual work and errors.
